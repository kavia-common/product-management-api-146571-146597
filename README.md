# product-management-api-146571-146597

Product Management API (Flask)
- Framework: Flask + flask-smorest
- Style: Ocean Professional (clean, modern, well-documented)
- Endpoints:
  - GET /                 -> Health check
  - GET /products         -> List products
  - POST /products        -> Create product
  - GET /products/{id}    -> Get product
  - PATCH /products/{id}  -> Partial update product
  - PUT /products/{id}    -> Replace product
  - DELETE /products/{id} -> Delete product

Run
- python -m pip install -r product_api_backend/requirements.txt
- python product_api_backend/run.py
- Docs available at /docs and OpenAPI JSON at /docs/openapi.json

Notes
- In-memory storage via ProductService to keep things simple; swap service with real DB adapter when available.
- Request validation and response schemas via Marshmallow; OpenAPI auto-generated by flask-smorest.
